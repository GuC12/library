# Catalogue sources

Complete original-language public-domain works. No modern translations are used. Original Gutenberg files retain their license. Wikisource transcription attribution: linked source pages and contributors (CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/).

Reader transformations: HTML navigation and source editorial notes removed, nonbreaking spaces normalized, Gutenberg line-wrapped prose reflowed, text split into reading pages without removing non-whitespace characters. Original text/HTML downloads in sources/, EPUB cover archives in .catalog-sources/; checksums in provenance.json.

Covers: original vector edition designs; Alice, Sherlock Holmes and Treasure Island use cover images extracted from their Gutenberg EPUB archives.
